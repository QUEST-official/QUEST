# QUEST ICML 2026 Project Page

Static GitHub Pages project page for:

**Uncertainty-Guided Exploration and Stable Planning for Sparse-Reward Manipulation from Limited Demonstrations**

## Edit

- Paper metadata, abstract, resource links, and BibTeX live in `index.html`.
- Page styling lives in `styles.css`.
- Web figures are generated from the PDFs in `assets/pdf/` and referenced as `assets/pdf/*.png`.
- Benchmark, ablation, and real-world sections use figure assets from `assets/pdf/`.
- The webpage intentionally does not expose a paper PDF link.

## Deploy With GitHub Pages

1. Push this repository to GitHub.
2. Open **Settings -> Pages**.
3. Select **Deploy from a branch**.
4. Choose `main` and `/root`.
5. Visit the generated GitHub Pages URL after the deployment finishes.
